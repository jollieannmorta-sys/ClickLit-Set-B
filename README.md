# Teacher Jollie's Reading Adventure (Set 2)

A second set of reading games for pupils of Froilan E. Lopez Elementary School, Tayabas City. All words, sentences and stories are new. The format is new too: an adventure map with 8 worlds, badges, ranks and a printable certificate.

## The 8 worlds
1. Phonics Park: short vowel words
2. Blend Beach: blends and digraphs
3. Vowel Valley: long vowels, vowel teams, bossy r
4. Syllable Spaceport: big words in syllables
5. Sight Word Safari: tricky words
6. Word Wizard Tower: meanings, opposites, word parts, idioms
7. Story Island: stories, details, story order
8. Grade 6 Summit: long words, fact or opinion, cause and effect, author's purpose, a longer passage

46 activities in all.

## Activity formats
- Read aloud with the 🎤 pronunciation check (words and sentences). The pupil hears the word first (🔊 Listen), then reads it, and the browser shows which words were read correctly.
- Picture match, Build the word (tap letter, digraph or syllable tiles), Listen and spell (type what you hear), Put in order (words or story lines), Fill the blank, Match them, Quiz, Story and questions.

## Rewards
Stars (1 to 3) for each activity, a 🏅 badge for each finished world, and a rank from Baby Bird to Reading Champion. Pupils can print a certificate with their name.

## Put it online with GitHub Pages
1. Unzip the file. You will get 7 files: `index.html`, `styles.css`, `data.js`, `app.js`, `README.md`, `logo.png`, `favicon.png`.
2. Create a NEW repository on GitHub (for example `Teacher-Jollie-s-Reading-Adventure`) so it does not replace Set 1.
3. Click **Add file → Upload files** and drag the 7 files (the files themselves, not the zip and not the folder). Click **Commit changes**.
4. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. After a minute your site is at `https://<your-username>.github.io/<repository-name>/`.

Important: the file names must stay exactly as they are. If a file name has "(1)" in it, rename it.

## Change the content
Open `data.js`. Add words, sentences or questions in the `WORLDS` list. Pictures for words are in `PICS`. Your name and school name are in `SITE` at the top.

## Printable sheets
On the home page: **My score sheet** (stars earned on that device, with a box for the teacher's pronunciation rating), **Class record sheet** (blank grid for up to 80 pupils, W1 to W8), and **My certificate**.

## Notes
- The mic check works best on Chrome or Edge, needs internet and microphone permission. Other browsers still get Listen and self-check buttons.
- The mic check shows only whether the browser recognised the word. It is a guide, not a final judge of pronunciation. Teacher listening is still the best check.
- Stars are saved only in that pupil's browser on that device. Set 2 keeps its own stars, separate from Set 1.
